# CtrlV - YX剪贴板管理器

Windows 剪贴板管理工具，基于 WPF (.NET 8) 开发。

## 功能

- 📋 剪贴板历史记录 — 自动记录复制的内容
- ⭐ 收藏夹 — 固定常用内容，重启不丢失
- ⌨️ 全局热键 — 默认 Ctrl+Alt+V 呼出，支持自定义
- 🖥️ 系统托盘 — 后台驻留，随时调用
- 🚀 开机自启 — 可选开机自动启动

## 运行环境

- Windows 10/11
- .NET 8.0 Runtime

## 构建

dotnet build CtrlV/CtrlV.csproj

## 使用

1. 运行 CtrlV.exe
2. 托盘出现蓝色图标
3. 按 Ctrl+Alt+V 呼出剪贴板
4. 右键托盘图标可进入设置
